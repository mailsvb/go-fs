Add repository

The repository is a folder the http server serves. For packages put into it the oldest versions beyond keep are removed, and the metadata clients read is written anew and signed with its key: rpms are signed with it too, APKs keep the signature of their developer. A jellyfin or a subsonic repository is a music library instead, which removes and signs nothing: Jellyfin or OpenSubsonic clients log in to it with the accounts of go-fs, and its folder can only be read with one. A jellyfin and a subsonic repository may share their folder. The folder is made when it is not there yet. The repository is written to the file at once; nothing else on this page is.
